这是课程的最后一章，我们将完成一个贯穿全部所学知识的综合项目。从域名到安全，从 CDN 到自动化，把所有知识融合在一起。

## 核心知识

### 综合项目：个人数字基础设施

本项目涵盖：

1. **域名与 DNS**：注册域名，配置 DNS 记录
2. **网站搭建**：使用 Pages 部署个人网站
3. **安全防护**：配置 SSL、WAF、DDoS 防护
4. **CDN 加速**：配置缓存规则，全球加速
5. **Zero Trust**：搭建安全的内部服务访问
6. **个人云**：R2 文件存储 + D1 数据库
7. **API 自动化**：使用 Terraform 管理所有配置
8. **运维监控**：配置告警和分析面板

### 项目架构

```
用户 → Cloudflare DNS
     → Cloudflare CDN/WAF
     → Pages (网站)
     → R2 (文件存储)
     → Tunnel (内部服务)
     → Workers + D1 (API服务)
```
