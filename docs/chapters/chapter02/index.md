# 第02章 家庭网络基础

## 本章目标

学习完成后，你可以：

- 说出家里上网都需要哪些设备，各自管什么事
- 分清「Wi-Fi」和「互联网」到底是不是一回事
- 讲清楚光猫、路由器分别解决什么问题
- 理解 IP 地址是「网络里的门牌号」，以及内网、公网的区别
- 知道 NAT 为什么能让全家用一个号码上网，端口又是什么
- 明白 IPv6 出现的原因，以及为什么在家里访问自己的设备需要「公网访问方案」

## 1. 家庭网络组成：你家的「网络小区」

如果把你家的上网环境想象成一个**小区**，事情就很好理解了。

- **运营商线路（光纤 / 宽带）**：相当于小区外面那条**主干道**，把整个小区连到城市之外的大世界（互联网）。
- **光猫**：相当于小区的**大门守卫 + 翻译员**。运营商送来的光信号（光里的数据）电脑看不懂，光猫把它「翻译」成网线能传的电信号。
- **路由器**：相当于小区里的**物业调度中心**。它负责给每家每户分配内部门牌号、指挥数据该往哪走、并把多台设备连在一起。
- **网线 / Wi-Fi**：相当于楼里的**走廊和电梯**，把数据送到各个房间（手机、电脑、电视）。
- **上网设备**：手机、电脑、智能电视、摄像头……就是住在各个房间里的「居民」。

一句话：**主干道进来 → 大门翻译 → 物业分配门牌并调度 → 走廊送达各家**。这就是一次完整的家庭上网链路。

## 2. Wi-Fi 与互联网：不是一回事

很多人以为「连上 Wi-Fi 就等于上网了」，其实这是两件事。

- **Wi-Fi** 只是**你家和手机 / 电脑之间的无线连接**，相当于从你家门口到小区物业的「内部无线步道」。它只管把你设备的数据送到路由器，管不了外面的世界。
- **互联网** 是**全球无数网络连成的大网**，相当于小区外面的整座城市、乃至全世界。

现实里常见的困惑就来自这里：

- 路由器坏了，Wi-Fi 信号可能还在，但你已经「连上了路由器却上不了网」——因为步道通，但大门没连到城市。
- 所以判断标准是：**有 Wi-Fi 不等于有互联网，有互联网也不一定非得用 Wi-Fi**（插网线一样能上）。

## 3. 光猫与路由器：各管一摊

### 光猫（Modem）

「Modem」是「调制解调器」的缩写。它的工作很单纯：

- 把运营商光纤里的**光信号** ↔ 家里网线用的**电信号**互相转换；
- 同时完成运营商身份的**认证**（证明你这个账号交了费、允许接入）。

你可以把它理解为：**专门负责「对外接通」的那道门**。没有它，外面的数据进不来，家里的数据出不去。

### 路由器（Router）

路由器负责「对内管理」和「指挥交通」：

- **分配门牌号**：给每台设备发一个内网 IP（见下文），就像物业给每户发房间号；
- **转发数据**：你点开一个网页，路由器知道「这个请求该从大门出去」，把数据送到光猫；
- **组建局域网**：让家里的手机、电脑、电视能互相访问（比如手机投屏到电视）；
- **提供 Wi-Fi**：多数家用路由器自带无线功能，相当于把「走廊」也做成了无线版。

> 小知识：很多家庭用的是「光猫 + 路由一体机」，运营商给的设备把两者合在一个盒子里。拆分来看，它们干的就是上面这两件事。

## 4. IP 地址：网络里的门牌号

你在第 01 章已经知道，**IP 地址是互联网中用来定位设备的「门牌号」**。在家里，这个概念会分成两种门牌。

常见的 IPv4 地址长这样：`192.168.1.10`、`114.114.114.114`。它由四段数字组成，每段 0–255。

打个比方：

- 你住在「幸福小区 3 栋 502」，这是你在家里的**内部房间号**；
- 而「幸福小区」在整个城市里也有一个**对外邮编/地址**，快递员从外面寄东西时用的就是它。

对应到网络：

- 你手机在家的「内部房间号」是**内网 IP**（如 `192.168.1.10`）；
- 你家对外的「小区地址」是**公网 IP**（如 `113.88.x.x`）。

## 5. 内网与公网：房间号 vs 小区地址

- **内网（局域网，LAN）**：你家里、公司里那张小网络。里面的设备用**内网 IP** 互相找对方。常见的内网段是 `192.168.x.x`、`10.x.x.x`、`172.16.x.x`。这些地址**只在你家内部有效**，外面的人不能直接用它们找到你——就像「3 栋 502」这个号，换个小区就没人认得。
- **公网（互联网，WAN）**：全球互通的大网络。设备要被全世界找到，就得有**公网 IP**。公网 IP 在全世界是唯一的，相当于「幸福小区」在城市里那一个唯一可投递的地址。

关键结论：**内网 IP 是「家里用的房间号」，公网 IP 是「对外收快递的小区地址」**。你在家里的每台设备都有房间号（内网 IP），但整个家通常只有一个对外地址（公网 IP）。

## 6. NAT：让全家用一个号码上网

问题来了：你家可能有十几台设备（手机、电脑、电视、摄像头……），但运营商通常只给你**一个公网 IP**。难道要申请十几个号码？

不需要。这就要靠 **NAT（网络地址转换）**，它就住在路由器里。

把 NAT 想成**小区的统一收发室**：

- 每户（设备）对内有个房间号（内网 IP），比如 `192.168.1.10`；
- 所有包裹出门时，NAT 把「房间号」换成「小区统一对外地址」（公网 IP），并记下「这是 10 号房间发出的」；
- 外面回的包裹寄到小区地址，NAT 再根据记录，精准转交给对应的房间。

于是：**外面只看到一个公网 IP，里面十几台设备却都能同时上网**。这就是 NAT 的核心价值——既省了 IP，又给家里加了一层「外面不能直接敲门到房间」的保护。

## 7. 端口：房间里的「分机号」

一个设备（一个 IP）往往同时跑很多程序：网页、微信、视频、游戏……数据回来时，怎么知道该交给哪个程序？

答案是**端口（Port）**，相当于房间里的**分机号 / 座位号**。

- IP 是「哪台设备」（哪个房间）；
- 端口是「这台设备上的哪个程序」（房间里的哪个座位）。

常见约定（就像默认的座位）：

- `80` 端口：普通网页（HTTP）
- `443` 端口：加密网页（HTTPS）
- `22` 端口：远程登录 Linux（SSH）
- `53` 端口：DNS 查询

所以一次完整通信其实是「**IP : 端口**」的组合，例如 `192.168.1.10:443` 表示「这台设备上的加密网页服务」。NAT 转发时，连端口一起记，才能把回包准确送到正确的程序。

## 8. IPv6：给每粒沙子都发一个地址

前面说的 `192.168.x.x` 属于 **IPv4**。IPv4 地址总数约 43 亿个——听起来很多，但全球设备早超过了这个数字（手机、电脑、摄像头、智能家电……），早就不够分了。所以我们才需要用 NAT「凑合」共用一个公网 IP。

**IPv6** 就是为了解决这个问题而生的新一代地址：

- 地址长度从 32 位扩大到 128 位，总量大到**号称能给地球的每粒沙子都分配一个地址**；
- 格式像 `2001:db8::1`，用冒号分隔的十六进制；
- 理论上每台设备都能拿到**独立公网地址**，不再依赖 NAT「凑合用」。

现实状况：IPv6 正在普及，但很多家庭网络仍是「IPv4 为主、IPv6 为辅」。理解它，是为了明白——**地址不够，才是后来一系列「访问麻烦」的根源**。

## 9. 为什么需要公网访问方案

既然 NAT 把全家藏在一个公网 IP 后面，新问题出现了：

> 你出门在外，想用手机看看家里的摄像头、连回家里的电脑、或者访问自己搭建的服务——**从外面怎么找到家里那台具体设备？**

难点在于：

- 家里设备只有**内网 IP**，外面根本没法直接寻址；
- 即使知道你家公网 IP，NAT 也不知道该把请求转给哪台设备、哪个端口；
- 更麻烦的是，很多运营商给的是「内网里的内网」（多层 NAT），你连自己真正的公网 IP 都没有。

所以，当你想「从外面访问家里的设备」时，就需要**公网访问方案**。它们本质上都是同一件事的不同解法——**在 NAT 这堵墙上，开一条安全、可控的通道**：

- **端口映射（端口转发）**：在路由器上登记「把外面的某端口请求，转给内网某设备的某端口」。最直接，但要求你有真公网 IP，且有一定安全风险。
- **内网穿透（如 Cloudflare Tunnel）**：不让外面主动敲门，而是由家里设备主动「向外建一条隧道」，外面通过中转访问。无需公网 IP，也避免了把端口暴露给全网。
- **DDNS**：因为家庭公网 IP 常会变，用它把「会变 IP」绑定到一个固定域名，省得每次手动查地址。

你在后面的章节会逐一实践这些方案。这里只要记住：**公网访问的本质，是想办法穿过 NAT，安全地把外面的请求送到家里那台具体设备。**

## 本章总结

- 家庭上网链路：**运营商线路 → 光猫（翻译+接通）→ 路由器（分配门牌+调度）→ Wi-Fi/网线 → 设备**。
- **Wi-Fi 是内部无线连接，互联网是全球大网**，两者不是同一件事。
- **光猫**管「对外接通」，**路由器**管「对内管理与调度」。
- **IP 地址是门牌号**：家里用的是**内网 IP**，对外用的是**公网 IP**。
- **NAT** 让全家共用一个公网 IP 上网，并顺带提供保护；**端口**用来在设备内部区分不同程序。
- **IPv6** 用近乎无限的地址，试图从根本上解决 IPv4 不够用的问题。
- 因为 NAT 把设备藏在内网，**从外面访问家里设备需要公网访问方案**（端口映射、内网穿透、DDNS 等）。
