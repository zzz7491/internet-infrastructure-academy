# 第2章 互联网基础知识

## 本章介绍

在深入使用 Cloudflare 之前，我们需要理解互联网是如何工作的。本章将讲解域名、DNS、IP 地址、HTTP/HTTPS 协议等基础知识，构建后续学习所需的底层认知。

## 学习目标

- 理解 IP 地址和域名的关系
- 掌握 DNS 的工作原理
- 了解 HTTP 和 HTTPS 的区别
- 理解 CDN 的基本概念

## 核心知识

### IP 地址

IP 地址是互联网上每台设备的"门牌号"。IPv4 格式如 `192.168.1.1`，IPv6 格式如 `2001:db8::1`。

### 域名与 DNS

域名是便于人类记忆的网址（如 `example.com`），DNS（域名系统）负责将域名翻译成 IP 地址。

### HTTP 与 HTTPS

HTTP 是浏览器与服务器通信的协议，HTTPS 是加密版本。SSL/TLS 证书是实现 HTTPS 的关键。

### CDN 简介

CDN（内容分发网络）通过在全球各地部署节点，让用户就近获取内容，加速网站访问。

## 常见问题

**Q: 为什么需要 DNS？**
A: 因为人类记不住 IP 地址，DNS 就像互联网的电话本。

**Q: HTTPS 一定安全吗？**
A: HTTPS 保证了传输过程加密，但不等于网站本身可信，仍需注意钓鱼网站。
