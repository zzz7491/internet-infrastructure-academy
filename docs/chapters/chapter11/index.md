## 常见问题

**Q: 优化后性能没有提升？**
A: 检查橙色云朵是否开启，确认缓存规则是否正确匹配。

**Q: 如何持续监控网站状态？**
A: 使用 Cloudflare Analytics 和第三方监控服务。
