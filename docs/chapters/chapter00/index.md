## 1. 为什么要学习互联网基础设施

普通用户每天都在使用互联网：

- 浏览网页
- 使用 APP
- 使用云服务
- 使用 AI 工具

但是，大多数人不清楚背后发生了什么：

- 数据是如何传输的？
- 服务器在哪里？
- 网站为什么可以被访问？
- 为什么需要 DNS？
- 为什么需要 HTTPS？

互联网基础设施，就是支撑这一切运转的底层系统。理解它，你就能从「只会使用」变成「真正理解并掌控」互联网。

---

## 2. 本课程适合哪些人

- 零基础互联网用户
- 想了解网络原理的人
- 想搭建个人服务器的人
- 想学习 Cloudflare、VPS、NAS 的人
- 想提高网络安全意识的人

无论你是普通用户、开发者，还是对技术好奇的爱好者，都可以从本课程中获益。

---

## 3. 学习路线

本课程分为五个阶段，由浅入深，循序渐进：

**阶段一：认识互联网**

建立对互联网的整体认识，理解浏览器打开网页的全过程，掌握 IP、DNS、TCP/IP、HTTP/HTTPS 等基础概念，并了解家庭网络与域名系统。

**阶段二：互联网基础设施核心**

深入 Cloudflare 生态，学习 DNS、SSL/TLS 安全通信、CDN 全球加速以及网站安全防护。

**阶段三：服务器与云计算**

从 VPS 服务器入门，到 Linux 基础命令，再到 Docker 容器技术，掌握现代服务器运维的核心能力。

**阶段四：个人数字基础设施**

将前面所学组合起来，实战 Cloudflare + VPS、Cloudflare Tunnel、NAS 个人云与家庭服务器，搭建属于自己的数字基础设施。

**阶段五：高级应用与综合实践**

学习 Zero Trust 安全体系、API 自动化运维，并通过综合项目实战把所有知识融会贯通。

---

## 4. 学习方式

本课程采用「三位一体」的学习方式：

- **理论学习**：理解每一个概念背后的原理，知其然也知其所以然。
- **实际操作**：跟着步骤动手配置，在真实环境中验证所学。
- **项目实践**：完成综合性项目，把零散的知识点串联成完整能力。

建议每一章都先读理论，再跟随操作，最后动手完成项目练习。

---

## 5. 学完以后可以做到什么

完成全部 18 章的学习后，你将能够：

- 理解互联网的工作原理
- 拥有并管理自己的域名
- 熟练使用 Cloudflare 管理站点
- 使用 VPS 部署个人服务
- 搭建 NAS 与个人云存储
- 构建并守护自己的数字基础设施

你会发现，原本「看不见」的网络世界，已经变得清晰可控。
