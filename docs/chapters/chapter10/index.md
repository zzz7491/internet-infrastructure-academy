# 第10章 R2、D1与个人云

## 本章介绍

Cloudflare 提供了 R2（对象存储）和 D1（Serverless SQL 数据库）两大存储产品。本章将学习如何用它们构建零成本个人云服务。

## 学习目标

- 理解 R2 对象存储的概念
- 掌握 R2 的上传、下载和权限管理
- 了解 D1 数据库的基础操作
- 学会搭建个人文件共享服务

## 核心知识

### R2 对象存储

R2 是兼容 S3 API 的对象存储服务，最大亮点是**不收流量费**。适合图片、视频、备份等存储场景。

### D1 数据库

D1 是 Cloudflare 的 Serverless SQL 数据库，基于 SQLite，适合轻量级数据存储。

### 个人云场景

- 图床 / 文件共享
- 个人博客数据库
- 笔记应用后端
- 家庭相册

## 实战操作

### R2 基础操作

1. 创建 R2 存储桶
2. 配置公开访问
3. 上传文件并获取链接
4. 绑定自定义域名

### D1 基础操作

1. 创建 D1 数据库
2. 编写 SQL Schema
3. 通过 Worker 连接 D1
4. 执行 CRUD 操作

## 常见问题

**Q: R2 免费额度是多少？**
A: 10 GB 存储 + 每月 100 万次 A 类操作 + 1000 万次 B 类操作。

**Q: R2 和传统云存储有什么区别？**
A: 核心优势是零流量费，直接从 Cloudflare 网络下载不收取费用。
