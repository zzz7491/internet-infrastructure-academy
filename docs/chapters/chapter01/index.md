## 核心知识

### Cloudflare 是什么

Cloudflare 是一家提供内容分发网络（CDN）、DNS 服务、DDoS 防护、SSL/TLS 加密以及其他安全和性能服务的美国公司。

### 核心产品线

- **DNS**：全球最快的权威 DNS 服务
- **CDN**：全球 330+ 城市的内容分发网络
- **SSL/TLS**：免费且灵活的 HTTPS 加密方案
- **WAF**：Web 应用防火墙
- **Zero Trust**：零信任网络安全方案
- **Workers**：边缘计算平台
- **R2 / D1**：对象存储和关系型数据库
