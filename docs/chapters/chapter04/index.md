# 第4章 Cloudflare DNS教程

## 本章介绍

DNS 是互联网的"电话本"。Cloudflare 提供全球最快的权威 DNS 服务，本章将深入学习 DNS 记录类型、代理模式、负载均衡等核心功能。

## 学习目标

- 掌握常见 DNS 记录类型
- 理解 Cloudflare 代理模式（橙色云朵）
- 学会配置和管理 DNS 记录
- 了解 DNS 安全和 DNSSEC

## 核心知识

### DNS 记录类型

- **A 记录**：域名指向 IPv4 地址
- **AAAA 记录**：域名指向 IPv6 地址
- **CNAME 记录**：域名别名指向另一个域名
- **MX 记录**：邮件交换记录
- **TXT 记录**：文本记录（常用于验证）

### Cloudflare 代理模式

橙色云朵 = 启用 Cloudflare 代理（流量经过 Cloudflare）
灰色云朵 = 仅 DNS 解析（流量直连源站）

## 实战操作

### 添加 DNS 记录

1. 进入域名的 DNS 设置页面
2. 点击「添加记录」
3. 选择记录类型并填写值
4. 切换代理状态
5. 保存

## 实验任务

- [ ] 为你的域名添加一条 A 记录
- [ ] 对比橙色云朵和灰色云朵的访问差异
- [ ] 添加一条 CNAME 记录（如 www 子域名）

## 常见问题

**Q: 橙色云朵和灰色云朵怎么选择？**
A: 需要 Cloudflare 保护（CDN/SSL/WAF）就开橙色；直连就选灰色。

**Q: DNS 更改多久生效？**
A: 通常在几分钟内，但受 TTL 设置影响。
