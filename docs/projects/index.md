## 课程项目

### 🎯 主项目：个人数字基础设施

贯穿全课程的综合实战项目，涵盖域名、DNS、CDN、安全、存储、自动化等全部模块。

**目标**：从零搭建一个生产级的个人数字基础设施。

**涉及技能**：
- Cloudflare DNS / CDN / SSL / WAF
- Pages / Workers
- R2 / D1
- Zero Trust / Tunnel
- Terraform 自动化
