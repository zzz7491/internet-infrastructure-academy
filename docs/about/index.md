# 关于课程

《人人都能学会的互联网基础设施》是一套**系统化、可动手实践**的在线课程，帮助你从零开始掌握现代互联网基础设施的核心能力。

## 课程定位

互联网基础设施是指支撑互联网运行的基础服务与设施，包括域名系统（DNS）、内容分发网络（CDN）、网络安全、服务器、存储等。你可以把它理解为互联网的"水电网"。

本课程不是零散的博客合集，而是一条**层层递进**的学习路线：从你每天都会用到的网页访问过程，到能够自己搭建并运维一套安全的个人 / 团队基础设施。

## 适合谁学

- **零基础爱好者**：没有计算机专业背景，但想搞懂互联网到底是怎么工作的。
- **个人站长 / 创作者**：希望让自己的网站更快、更安全、更省心。
- **远程办公与隐私关注者**：想要安全的远程访问、私有云与数据主权。
- **小型团队 / 创业者**：需要用最低成本搭建稳定可靠的网络服务。

> 如果你时间有限，完成前三个阶段（第0–10章）即可掌握最核心的互联网基础设施技能。

## 学习方式

1. **通读教材** —— 理解本章要解决什么问题。
2. **跟着操作做实验** —— 打开控制台，跟随步骤动手配置。
3. **记录学习笔记** —— 用自己的话总结核心知识点。
4. **完成实验任务** —— 验证你真的掌握了。

## 你将获得的能力

- 理解浏览器打开网页背后的完整链路（IP、DNS、TCP/IP、HTTP/HTTPS）。
- 熟练使用 Cloudflare 的 DNS、SSL/TLS、CDN 与安全防护能力。
- 拥有并运维自己的 VPS、Linux 服务器与 Docker 容器。
- 搭建家庭 NAS、私有云与安全的远程访问通道。
- 用 Zero Trust 与 API 自动化构建现代化的安全运维体系。
