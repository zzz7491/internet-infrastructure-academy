# 人人都能学会的互联网基础设施

> 从理解互联网运行机制，到建立自己的数字空间

这是一个面向普通人的互联网基础设施学习课程。

---

## 项目简介

互联网已经成为现代社会的基础设施。

每天，我们都在使用它：用手机沟通、浏览网页、把照片和文件存到云端、调用各种 AI 工具、积累属于自己的数字资料。互联网不再是少数人的专业领域，而是和自来水、电力一样，渗透进每个人的日常生活。

但是，很多人知道「如何使用」互联网，却并不了解它「如何运行」：数据是怎样在网络中传输的？网站背后是怎样一台台服务器在支撑？不同网络之间是怎样连接的？我们的信息是怎样被保护的？在 AI 时代，普通人又该如何管理属于自己的数据与数字资产？

本课程希望帮助普通人建立起一套完整、清晰、可长期使用的认知框架——不依赖某一个厂商、不绑定某一种工具，而是真正理解互联网基础设施的底层逻辑，并思考如何拥有自己的数字空间。

---

## 为什么创建这个课程

过去，互联网对大多数人来说只是一组「好用的工具」：能聊天、能查资料、能看视频。

现在，互联网已经成为生活的基础设施：工作、学习、社交、支付、创作，几乎都建立在这张网络之上。

未来，互联网、数据与 AI 将共同成为个人能力的重要组成部分。谁能理解并管理自己的数字空间，谁就更能掌握自己的数字生活主动权。

这种变化的本质，是人的角色在升级：

```
普通用户
   |
   使用互联网

高级用户
   |
   理解互联网

数字时代主人
   |
   拥有并管理自己的数字空间
```

本课程不培养工程师，而是希望让每一位普通读者，都能从「互联网的使用者」，成长为「互联网的理解者」，最终成为「自己数字空间的管理者」。

## 互联网基础设施知识体系

如果把整套课程想象成一座「数字城市」，那么所有章节最终都汇聚到同一套分层架构之中：

```
            AI 智能层
               ↑
          数据资产层
               ↑
          计算服务层
               ↑
          入口管理层
               ↑
          网络连接层
               ↑
          安全保护层
```

- **安全保护层**：身份认证、加密、HTTPS、备份与恢复，是所有数字活动的基础保障。
- **网络连接层**：IP、IPv6、TCP/IP，是把世界连接起来的「道路」。
- **入口管理层**：域名、DNS、Cloudflare，决定别人如何「找到」你的数字空间。
- **计算服务层**：服务器、VPS、Linux、Docker，是真正运行各种服务的「房子」与「房间」。
- **数据资产层**：NAS、知识库，是存放个人数字资产的「私人仓库」。
- **AI 智能层**：AI 与数字管家，是把数据、计算与服务连接成「智能能力」的顶层。

每一层都对应课程中的具体章节，它们不是孤立的技术名词，而是一套完整的个人数字基础设施。

## 课程特点

- **零基础友好**：从「为什么」讲起，不假设读者有任何技术背景。
- **从原理开始，而不是从工具开始**：先理解世界如何运转，再谈具体实现。
- **不绑定具体厂商**：用统一的比喻体系讲清原理，而不是推销某一家产品。
- **不依赖某一种技术路线**：提供看待基础设施的通用视角。
- **强调长期数字能力**：关注的是可以持续使用的认知，而非短期技巧。
- **面向未来互联网和 AI 时代**：把今天的网络基础，连接到明天的个人数字主权。
